# Frontend

Форма создания черновиков в стиле Авито. По умолчанию генерация подключена
к FastAPI backend по адресу http://127.0.0.1:8001. Данные отправляются на
POST /api/generate; backend обращается к Qwen через SSH-туннель.

HTML, CSS и JavaScript ES modules, Node.js 22+. Установка npm-пакетов не нужна.

## Запуск

Сначала запустите backend из корня проекта в отдельном терминале
(зависимости, ключ и .env описаны в [backend/README.md](../backend/README.md)):

```bash
backend/.venv/bin/python -B -m uvicorn backend.app.main:app \
  --host 127.0.0.1 --port 8001 --env-file backend/.env
```

Затем запустите frontend:

```bash
cd frontend
npm run dev
```

Откройте **http://127.0.0.1:5173**. Форма покажет готовность подключения Qwen.
Вставьте исходное объявление, выберите категории вручную и нажмите
«Сгенерировать черновики». Результаты можно редактировать и копировать.
Для каждой выбранной категории возвращается черновик. Если исходных сведений
недостаточно, появляется заготовка с пометкой о необходимости уточнения деталей.

Для проверки можно использовать описание:

> Укладываем плитку и керамогранит на стены и пол. Меняем смесители и устанавливаем раковины. Работаем в Казани. Стоимость согласуем после осмотра.

Выберите «Плиточные работы» и «Сантехника».

Кнопка подбора категорий использует локальную заглушку по ключевым словам:
результат автоматически отмечается в форме, его можно изменить вручную.
Генерация черновиков работает через Qwen. Ошибки генерации отображаются в форме
и не подменяются тестовыми черновиками.

Для другого адреса backend:

```bash
API_TARGET=http://127.0.0.1:8002 npm run dev
```

HOST и PORT задают адрес и порт frontend; по умолчанию 127.0.0.1:5173.
API_TARGET доступен только Node-серверу, SSH-ключи и параметры сервера Qwen
в браузер не передаются.

## HTTP-контракт

- GET /api/status — frontend-сервер проверяет GET /ready backend и возвращает
  mode, ready, model и доступность автоподбора categoryGeneration.
- POST /api/generate — JSON с title, description и categories: [{id, name}].
  Проксируется на тот же путь backend.
- Ответ генерации: drafts: [{categoryId, title, description}], warnings:
  [{categoryId, reason, message}]. reason=needs_details обозначает заготовку,
  которую нужно дополнить; категория при этом не пропускается.
- POST /api/categories обрабатывается локальной заглушкой frontend-сервера
  в обоих режимах и возвращает categories: [{id, name}].

Отмена запроса и изменение исходника защищают форму от устаревшего ответа.
Отмена в браузере не гарантирует остановку уже начатого вычисления на Qwen.
При недоступном подключении форма повторяет проверку статуса каждые 5 секунд.
После ошибки генерации статус также обновляется; backend восстанавливает свой
SSH-туннель автоматически, когда сеть становится доступна.

## Демонстрационный режим без Qwen

Включается только явно:

```bash
MOCK_API=1 npm run dev
```

Форма показывает отметку демонстрационного режима. Подбор по ключевым словам
и генерация выполняются локальными заглушками из scripts/mock-api.mjs.
Они не являются ответом модели. В этом режиме кнопка подбора категорий доступна.

## Проверка и сборка

```bash
npm test
npm run build
npm run preview
```

Сборка копирует клиентские файлы в dist/. Preview использует тот же backend
и порт, что dev. Не запускайте dev и preview одновременно на одном порту.

При размещении dist/ на другом сервере настройте обработчики /api/status и
/api/generate отдельно: Node-сервер и API-прокси в статическую сборку не входят.
