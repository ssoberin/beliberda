# Qwen3-Embedding-0.6B + SGDClassifier (Public Splits Baseline Comparison)

## Конфигурация эксперимента
- **Скрипт:** `avito_compare/scripts/qwen3_embedding_experiment.py`
- **Энкодер (frozen, без fine-tuning):** `Qwen/Qwen3-Embedding-0.6B` через `SentenceTransformer` (`normalize_embeddings=True`, `max_seq_length=8192`, размерность `1024`).
- **Инструкция для классификации:**
  `Instruct: Classify the renovation and repair service microcategories offered in the given Russian classified ad description\nQuery:`
- **Генерация эмбеддингов:** Google Colab Tesla T4, `torch.float16`, `batch_size=16`, `403.69 с` на все сплиты (`train`: `262.88 с`, `calibration`: `61.30 с`, `validation`: `63.47 с`, `official_208`: `15.50 с`); после прогрева `85.1 мс` среднее / `64.9 мс` медиана на объявление; пик RAM при кодировании `3377.1 MiB`, пик VRAM `6554.5 MiB`.
- **Классификатор:** `OneVsRestClassifier(SGDClassifier(loss="log_loss", penalty="l2", max_iter=1000, tol=1e-3, random_state=42))`.
- **Подбор `alpha` (5-fold CV строго на `train`, `3398` строк):** выбран `alpha=1e-6` (`OOF Micro-F1 = 0.88172` против `0.85571` при `1e-4`).
- **Время SGD и память (CPU):** обучение `2.82 с`, инференс SGD по готовому эмбеддингу `0.32 мс`, пик RAM `433.3 MiB`.
- **Калибровка порогов (строго на `calibration`, `728` строк):** `102: 0.275`, `103: 0.200`, `104: 0.750`, `105: 0.500`, `106: 0.200`.

## Выводы по паблик-сплиту
1. На одномерно-текстовых объявлениях публичного датасета замороженные 1024-мерные эмбеддинги `Qwen3-Embedding-0.6B` с линейным `SGDClassifier` уступают `TF-IDF (word + char_wb, 46k) + SGD` примерно на `4.9 п.п.` Micro-F1 (`0.88842` против `0.93712`).
2. Основной паттерн ошибок (`errors_sample.json`, `235` ошибочных строк из `729`): при усреднении длинного объявления в один вектор теряется точность по границам смежных работ (ложные срабатывания `102`/`104`/`106` в общих текстах "ремонт под ключ") и отдельные редкие упоминания в длинных списках услуг (`FN`).
