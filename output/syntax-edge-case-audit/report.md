# Частичный отказ от услуги: публичные данные и C_syntax

2026-11-15. Только исследование и инференс сохранённой C_syntax. Архитектура, веса, порог 0.5, обучающие и проверочные данные не изменены.

## Что требуется по ТЗ

В `mvp/innoglobalhack_avito/innoglobalhack_avito/Innoglobalhack-Avito_2026.md`, пункты 1–3 раздела задачи: выделять предлагаемые услуги и создавать дополнительные черновики для категорий, отличающихся от исходной. В `microcategories-guide.md`, раздел 103: укладка плитки на стены и пол относится к одной категории 103. Запрет утверждать возможность отдельного заказа в черновике не исключает действительно предлагаемые работы из классификации.

Поэтому для входа «Плитку на пол не укладываем, только на стены.» при source_mcId=101 правильная экспертная интерпретация — [103]. Отказ касается пола, стены предлагаются. Если исходная категория 103, результат должен быть [] из-за исключения исходной категории. Это интерпретация по ТЗ, а не официальная метка этого придуманного примера.

## Решение по обработке

Подтверждён общий полезный случай: частичный отказ не отменяет положительное предложение другой подуслуги. Подтверждён частный сбой с пропущенным глаголом, но его наличие в public test не установлено. Реальный ближайший пример с обоями модель решает правильно. Добавить правило под единственную фразу без проверки регрессий означало бы менять входные признаки обученного CatBoost без доказанного улучшения. Поэтому рабочая обработка и веса сейчас не меняются. Фиксируем этот случай как известную неуспешную диагностическую пробу, а реальные объявления — как регрессионные контрольные примеры.

Для исправления нужен отдельный контролируемый эксперимент: ограничить область отрицания и учитывать восстановление пропущенного действия; затем проверить положительные и отрицательные контрпримеры и общие метрики. Текущий аудит такого улучшения не заявляет.
