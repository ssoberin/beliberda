## Системные выводы из корпуса

- В public test **26 групп повторяющихся описаний (95 строк)**, из них **13 групп с противоречивыми метками (56 строк)** при одинаковых заголовках. Из 104 FP старой модели **59** находятся в этих 56 строках; и на уникальных описаниях F1 лишь **0.729**, то есть шум меток объясняет не всё. На противоречивых строках F1 старой/новой модели 0.815/0.770, на остальных 0.810/0.794.
- У public test 106/208 пустых меток против 203/729 в public validation. Часть пустых меток противоречит явным спискам услуг. Нельзя исправлять модель, заставляя её отвечать пусто на такие тексты.
- На новом test 75 `template_new_long` получили FP 44→3 при почти неизменных FN 54→52 (контроль→новая), то есть модель стала осторожнее на шаблонах. На 45 `template_negation_long` FN **62→72**, F1 **0.368→0.275**: смысл отрицания не решён.
- Из 2170 новых строк 1100 производны от исходных real-public; остальные длинные конструкции собраны из ядра и фрагментов. `meta.core`, семейства и общий фон позволяют шаблонно обобщать между new train/test. 225 исходных строк имеют `confidence=medium`; 18 строк с конфликтующими метками для одинакового текста изолированы из эксперимента.

## Предзаданные пропорции нового train — только validation

Одинаковые пять голов, старые public train (3398) + v2 train (8464), фиксированный порог 0.5. Внутри каждого `set` нового train по стабильному SHA-256 порядку выбраны вложенные 0/25/50/100%; исходный порядок строк сохранён для SGD. **Ни public test, ни новый test при выборе доли не вычислялись.** Подробности: `/srv/Hakaton/results/postoyanka_v2/mixture_validation.json`; код: `mixture_validation.py`.

Проверка только на validation показывает **обмен**: новый набор улучшает свою выборку, но не превосходит контроль на public validation при любой предзаданной доле. На v2 нет устойчивого изменения. Это не основание выбрать «лучшую» пропорцию по public test; рабочая baseline-модель на public validation (0.9349) остаётся выше всех этих вариантов. Нужны независимая вручную согласованная разметка и оценка отдельно по реальным объявлениям и отрицаниям. Рабочая модель/сервис не менялись.
