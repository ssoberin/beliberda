# Малое дополнение V3: услуги в конце объявления

`train_addition.jsonl` — 60 новых объявлений, добавляются к public3398 + V3clean2921 только в эксперименте `output/tail-services-v3-experiment/`.

`test_holdout.jsonl` — 20 отдельных авторских объявлений; не обучать на них и не использовать для early stopping. Это дополнительные проверки, исходные public/V3 тесты остаются прежними.

Во всех входах `mcId=source_mcId=101`, выходы102–106. `offered_microcategories` содержит числовые ID по существующему формату V3; `found_microcategories` — объекты `mcId,label`. Объяснения разметки только в `annotation_review.json`, в обучаемом тексте их нет. Каталоги и builder воспроизводят JSONL побайтно.

Все тексты написаны заново. Основные типы: фактическое предложение услуги в характеристиках/последнем абзаце, разные названия работ, настоящая услуга с SEO-хвостом, материалы/проекты/чужой контекст без предложения целевых работ. Длинный контекст индивидуален. Набор экспертно размечен автором; независимой человеческой проверки нет.

Существующие записи V3 не редактируются. Это отдельно подключаемое дополнение; основная модель не заменяется автоматически.
