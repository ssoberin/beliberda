# Дополнительный синтетический тест

`public-test-synthetic-300.parquet` — 300 новых объявлений на русском языке в схеме
исходного `public-test-dataset.parquet`: `title: string`, `description: string`,
`categories: list<string>`. Метки — названия дополнительных микрокатегорий
102–106; исходная категория 101 в ответ не включается.

150 строк не содержат дополнительных услуг, остальные включают от одной до пяти.
В текстах есть отрицания, цитаты о желаемых работах, условные предложения,
упоминания чужих исполнителей и прямые предложения услуг. Все 300 описаний
различны; исходный публичный тест не используется при генерации. Скрипт
`generate_secondary_test.py` детерминированно пересоздаёт файл (нужен `pyarrow`).
Примеры строк и сравнение с train/validation: [EXAMPLES-AND-COMPARISON.md](EXAMPLES-AND-COMPARISON.md).

Это **синтетический**, шаблонно сгенерированный тест, а не независимая
ручная разметка реальных объявлений. Не использовать для обучения или настройки
порогов, если нужна честная оценка на нём; результаты на нём не эквивалентны
официальному тесту.
