# 100 авторских текстов для обучения и20отдельных контрольных

`data.jsonl`:50индивидуально написанных сценариев, по две контрастные версии.
`test_20.jsonl`:10других структурированных сценариев, по две версии; вне обучения.
Исходные own_v3 и public не редактировались. Эти файлы добавляются отдельно.

| Тема | Train текстов | Отдельный test |
|---|---:|---:|
| Сравнение услуги/материала/исполнителя |30|4|
| Частичный отказ внутри категории |20|4|
| Своя команда, заказчик, независимый мастер |20|4|
| Привязка ответа/местоимения к услуге |20|4|
| Текущий статус, время, условия заказа |10|4|

Вход: только description иmcId. Source всегда101; размечаются предлагаемые
категории102–106. Вне-scope услуги, например сборка мебели, могут предлагаться
при пустом массиве целевых меток. В позитивной evidence сохранён контекст,
необходимый для разрешения местоимений и ответов. Само упоминание услуги
в сравнении, пожелании заказчика или чужом предложении недостаточно.

Контекст каждого сюжета написан отдельно. Его две версии меняют существенное
утверждение, исполнителя или статус и имеют разные ответы. Полные тексты и
объяснения: examples.md. Сборка только сериализует cases.py/test_cases.py,
случайного создания формулировок и заимствования исходных объявлений нет.

Метки авторские, после повторного смыслового просмотра. Это НЕ независимая
двойная человеческая разметка и НЕ доказанно репрезентативная выборка Авито.
Набор целевой:20пустых,76однометочных и4двухметочных обучающих ответов;
он дополняет, а не заменяет общий корпус. Две версии — один сюжет, не два
независимых наблюдения. При split/bootstrap сохранять целые group_id.

Пользователь разрешил включить100текстов в обучающий пул.20новых контрольных
туда не включаются. Нельзя выбирать пороги или гиперпараметры по этим20.

```bash
python3 -B datasets/context_pairs_100/build.py
python3 -B -m unittest discover -s datasets/context_pairs_100 -p 'test_*.py' -v
```

Служебные поля evidence,topic,pair_rationale,group_id,variant,offered/found и
discriminating_span раскрывают ответ; не включать их в признаки.
