# V3: обучающая часть после исключения 79 искусственных текстов

Для следующих экспериментов с очищенным v3 используйте **train.jsonl: 2921 строка**.
База — исходный `dataset_v3@0882f80`, revision2. Исключены79строк с5–6повторами
одной статусной рамки (руководитель/бригада, FAQ, исправление прежнего отказа,
отказ от бесплатности). Список согласован пользователем после статического аудита.
Это экспертная оценка реалистичности, не установленная ошибка разметки.

|---|---:|---:|

| validation |600|600|
| test |600|600|

Проверочные файлы скопированы байт-в-байт. Тексты, метки и порядок оставшихся
обучающих строк сохранены; пересечений описаний train с проверочными частями нет.
Оригинальная ревизия и прошлые эксперименты остаются доступными для воспроизведения.
Экспериментальная ревизия с250заменами здесь не используется.

`quarantine/excluded_train_79.jsonl` — исключённые записи для аудита и возможной
переработки. **Не добавлять эту папку обратно в train и не считать её независимым
test**: модели уже видели эти тексты при предыдущем обучении.
`exclusion_manifest.json` содержит IDи причину; `stats.json` — хэши и распределения
до/после. Полный исходный аудит: `output/v3-realism-screen/report.md`.

число пустых, одно- и двухметочных ответов не изменилось. Баланс не выравнивался
дубликатами. Остальные393из472кандидатов широкого скрининга автоматически
не исключались; просто сложные отрицания и чужие исполнители сохранены.

Воспроизведение:

```bash
python datasets/own_v3_clean/build.py --base /path/to/original/datasets/own_v3
```

Сборщик проверяет79исключений, неизменность оставшихся строк, байтовые хэши
проверочных частей, неизменность источников и отсутствие train/holdout-пересечений.
