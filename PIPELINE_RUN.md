# Обычный запуск FastAPI с C_syntax

После установки зависимостей (Python3.11+):

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
.venv/bin/python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 18001
```

При старте lifespan загружает и прогревает frozen Qwen3-Embedding-0.6B, SGD,
Natasha/Slovnet и CatBoost. После startup приложение принимает запросы.
Пайплайн не запускается shell-командой или отдельным процессом на каждый запрос.
Один экземпляр модели на процесс Uvicorn; обычный запуск использует один процесс.

Оба маршрута /api/categories и /api/create отправляют классификацию в одну
ограниченную очередь: один активный inference и до16 ожидающих заданий.
Вычисление идёт в выделенном потоке и не блокирует asyncio event loop.
Переполнение даёт503, отменённые задания пропускаются. При остановке очередь
закрывается, активное вычисление завершается, поток освобождается.
/api/create сохраняет потоковые NDJSON-события и отдельные результаты запросов.
HTTP-вызовы Qwen-генератора имеют прежний отдельный лимит concurrency.

C_syntax выбрана по умолчанию, флагов выбора классификатора нет.
Веса/queries в models/c_syntax, проверяются поSHA256; код chunker/syntax совпадает
с обучением. Qwen0.6B берётся из локальногоHFкэша, при отсутствии скачивается
закреплённаяrevision. GPU используется автоматически при доступности.
Выходы102–106, пороги0.5, source исключается, [] допустим. Нет обрезки до6000.
Исходная C_syntax на6319строках остаётся основной; +60 и Luna — отдельные кандидаты.

Frontend запускается отдельно (Node22+):

```bash
cd frontend
node scripts/server.mjs
```

Откройте http://127.0.0.1:5173. Для текстов нужен OpenAI-совместимый Qwen7B API
(по умолчанию127.0.0.1:8000/v1, avito-qwen). Это отдельный уже существующий
генератор; загрузкаembedding-классификатора не поднимает7Bсервер.
НастройкиAPI/SSH — backend/.env.example; при обычномuvicorn backend/.env читается автоматически,
переменные окружения имеют приоритет. Для llama.cpp установитеQWEN_TOKENIZE_BEFORE_GENERATE=0,
если егоAPIне поддерживаетvLLM/tokenize. Сам классификатор от генератора независим.

Проверки: python -m pytest backend/tests -q; в frontend — node --test.
Реальный retrieval/SGD/Natasha/CatBoost воспроизводит пять старых входов по
frozen embeddings с точностью1e-12. HTTP-тест использует настоящий Qwen0.6B
и заглушкуHTTPгенератора, а не настоящий7B. Датасеты/пороги/обучение не менялись.
